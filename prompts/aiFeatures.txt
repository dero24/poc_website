AI INTEGRATION:
- Use window.morphicGroqChat(messages, opts) - handles model/tokens automatically
- window.groqKey and window.selectedModel available globally
- Auto-adjusts max_tokens per model (gemma:512, llama-3.3:2048, llama-3.1:4096)
- Always include loading states, error handling, user feedback

USAGE:
const response = await window.morphicGroqChat([
  { role: 'system', content: 'Brief system prompt' },
  { role: 'user', content: userInput }
], { temperature: 0.7 });

REQUIREMENTS:
- Concise prompts to maximize output quality within token limits
- Full in-browser functionality, no external dependencies
- Graceful error handling with user-friendly messages
